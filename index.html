🔧 ตั้งค่าครั้งแรก

ใส่ข้อมูลเชื่อมต่อฐานข้อมูล Supabase ของร้าน (Project Settings → API) ทำครั้งเดียวต่อเครื่อง

ยังไม่มีโปรเจกต์? สมัครที่ supabase.com สร้างโปรเจกต์ใหม่ แล้วกลับมากรอกที่นี่ ใช้ anon public key เท่านั้น ห้ามใช้ service_role

🗄️ ติดตั้งฐานข้อมูล (ครั้งเดียว)

⚠️ โปรเจกต์นี้มีตารางเดิมอยู่แล้ว (เช่น products) น่าจะเคยใช้กับโปรแกรมอื่น การติดตั้งจะ error เพราะชื่อตารางซ้ำ และไม่ควรลบข้อมูลเดิมถ้ายังต้องใช้ แนะนำ: สร้างโปรเจกต์ Supabase ใหม่ (ฟรี) แล้วกด "เปลี่ยนโปรเจกต์ Supabase" ด้านล่าง ใช้ URL และ anon key ของโปรเจกต์ใหม่

ฐานข้อมูลของแอปยังไม่ได้ติดตั้ง ทำตามนี้:

  1. กด คัดลอก SQL
  2. กด เปิด SQL Editor แล้ววางทั้งหมด กด Run
  3. กลับมากด ตรวจอีกครั้ง (ถ้ารัน SQL สำเร็จแล้วแต่ยังขึ้นหน้านี้ รอ 1 นาทีแล้วลองใหม่)
ใช้กับโปรเจกต์ใหม่เท่านั้น (ถ้าเคยติดตั้งแล้วจะซ้ำและ error)

🔧 เข้าสู่ระบบ

สร้างบัญชีใน Supabase → Authentication → Users → Add user (ติ๊ก Auto Confirm User)

👑 ตั้งเป็นเจ้าของร้าน

ยังไม่มีเจ้าของร้านในระบบ บัญชีนี้จะเป็นเจ้าของร้านคนแรก (ทำได้ครั้งเดียว)

⏳ รอเจ้าของร้านอนุมัติ

บัญชีนี้ยังไม่ได้รับสิทธิ์ใช้งาน ให้เจ้าของร้านเพิ่มอีเมลของคุณที่ ตั้งค่า → พนักงาน
